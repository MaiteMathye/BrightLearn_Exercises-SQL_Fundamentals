# BrightLearn_Exercises_SQL_Fundamentals
This project demonstrates my understanding of basic SQL querying and data retrieval as part of my journey in data analytics and data science with BrightLearn Institution.

# Exercises Covered
*Exercise 1 SQL Fundamentals: Covered basic SQL concepts including SELECT, WHERE, filtering, sorting and working with database tables.
*Exercise 2 SQL Aggregates & Operators: Practised aggregate functions such as COUNT, SUM, AVG, MIN, and MAX along with SQL operators and conditions.
*Exercise 3 SQL CASE Statements: Learned how to use CASE statements to apply conditional logic, categorize data and create new calculated results.

**These exercises have helped me build a stronger foundation in SQL, data manipulation, filtering, aggregation and conditional logic as part of my journey into data science and analytics.**
